# 뮤직 플레이어

알송처럼 가사 싱크를 보여주는 음악 플레이어를 Orca 오른쪽 사이드바 패널로 만든 플러그인입니다. 패널 위쪽 탭으로 **음악**과 **유튜브**를 오갑니다.

## 음악 탭

- 재생/일시정지, 이전/다음, 셔플, 반복(전체/한 곡/안 함), 볼륨, 탐색
- 가사: 같은 이름의 `.lrc` 파일, 또는 MP3에 들어 있는 가사(ID3 `USLT`). 같은 시각의 여러 줄(원문·발음·번역)을 한 묶음으로 보여주고, 줄을 누르면 그 위치로 이동합니다. 싱크는 ±0.5초씩 조절합니다.
- MP3 태그(제목·아티스트·앨범아트) 표시, 태그가 없으면 `아티스트 - 제목.mp3` 파일 이름을 씁니다.
- 파일·폴더 추가 버튼 또는 패널에 끌어다 놓기. 단축키: Space 재생/정지, ←/→ 5초 이동.
- 볼륨·셔플·반복 설정은 플러그인 저장소(`storage:own`)에 저장됩니다.

재생 목록은 패널을 다시 열면 비워집니다(패널은 디스크 경로를 알 수 없음).

## 유튜브 탭

- 유튜브 탭을 열거나 검색어를 비우고 검색/초기화하면 기본값으로 오늘 업로드된 AI 기술 트렌드 인기 영상(조회수순) 30개를 아래에 표시합니다.
- 검색어를 넣으면 worker(`worker.mjs`)가 유튜브 검색 페이지를 읽어 영상 목록(썸네일·길이·채널·조회수)을 아래에 보여줍니다. 공식 API 키 없이 페이지를 읽으므로 유튜브가 구조를 바꾸면 고쳐야 합니다.
- 영상을 누르면 위쪽 플레이어 영역에서 재생합니다. 패널은 iframe과 외부 미디어가 막혀 있어(CSP `frame-src 'none'`, `media-src 'self' blob:`) worker가 **yt-dlp**로 360p mp4를 임시 폴더에 받은 뒤 조각으로 넘기고, 패널이 blob으로 재생합니다. 받는 동안 진행률이 표시됩니다.
- 유튜브 영상 주소를 넣으면 검색 없이 그 영상을 재생합니다.

### yt-dlp

worker는 플러그인 전용 폴더(`%LOCALAPPDATA%\orca-music-player\yt-dlp.exe`), `PATH`, winget 설치 폴더 순서로 `yt-dlp.exe`를 찾습니다. 없으면 플레이어 영역에 **yt-dlp 설치**(공식 GitHub 배포판을 전용 폴더에 받음)와 **브라우저 탭으로 열기** 버튼이 나옵니다. 받지 못하면(차단, 업데이트 필요 등) 이유와 함께 브라우저 탭으로 여는 버튼을 보여줍니다.

회사 보안망에서는 유튜브 영상·검색이 차단 페이지로 바뀌어 동작하지 않을 수 있습니다. 개인 용도로만 쓰세요.
